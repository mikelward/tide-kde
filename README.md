# tide-kde

tide on KDE Plasma: [tide](https://github.com/mikelward/tide)'s tiling,
workspaces, dim and keys as a KWin 6 script, with tide's launcher beside it.
Plasma's panel, notifications, lock and settings stay its own.

**Status: exploration.** Nothing is built yet. [SPEC.md](SPEC.md) says what
KWin allows, how each of tide's features maps onto it, and what can't be
done. [TODO.md](TODO.md) is the plan.

tide-kde supersedes tide's launcher on Plasma, and takes over its
`tide-kde.service` (SPEC.md §5).
